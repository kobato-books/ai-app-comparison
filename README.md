# 短い指示で、AIはどんなアプリを作る？

「ほんの簡単な指示だけで、使えるアプリは作れるの？」

そんな疑問から、Claude・Grok・Gemini・ChatGPTに同じ指示を送り、Webアプリを作ってもらう実験を始めました。

このリポジトリには、各AIが作ったアプリと、制作・確認の記録をまとめます。GitHub Pagesで、実際に試せる比較ページを公開する予定です。

## 比較するポイント

- どんな画面や機能を作ったか
- 指示していない部分を、AIがどう補ったか
- 実際に動くか、使いやすいか
- 追加の指示や修正がどれくらい必要だったか

## 実験の条件

共通の指示文に加え、使用モデル、無料・有料プラン、過去の会話の有無、追加指示や修正内容を記録します。

ChatGPTは、普段使っているアカウントの会話や好みの影響を避けるため、別アカウントで試しています。こちらのAIの愛称は「チャコ」です。

これは各AIの性能を厳密に順位付けするものではなく、今回の指示と利用条件で、どんな違いが生まれるかを観察する個人の実験です。

制作過程や感想は、noteにも掲載予定です。
